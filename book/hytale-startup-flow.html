Sentry telemetry

  • serverContext - name, max-players
  • universeContext - path, player-count, world list
  • pluginsContext - list of plugins, state (enabled/disabled/failed), versions
  • packsContext - version and manifest data about assetpacks
  • "unknown" - server hardware UUID, auth mod, Hytale username/UUID for selected profile, IP address?
  • "scope" - hardware UUID (again?), OS name and version, HytaleServer version/revision/patchline/environment

This data is sent to Hytale on server startup, unless Sentry is disabled. Sentry can be disabled by:

  • option flags
  • by the presence of early plugins
  • by running a "development build" (probably a way for Hytale employees to not flood Sentry)
